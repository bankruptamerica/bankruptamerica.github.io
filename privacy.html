Privacy Policy

Last updated: November 12, 2026

What this app is

The Bankrupt America uploader is a private tool, run only on the channel owner's own computer, that uploads videos, thumbnails and video details to the Bankrupt America YouTube channel. It has no other users and is not offered to the public.

Data it accesses

With the owner's permission, through Google OAuth, the app uses the YouTube Data API to:

  • upload videos and thumbnails to the owner's channel (scope youtube.upload);
  • read the processing status of those uploads (scope youtube.readonly).

It does not access any other Google data and does not collect data about viewers.

Storage and sharing

The OAuth token is stored only on the owner's computer. No data is sold, shared with third parties, or used for advertising. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account permissions.
